# TechFlow — Modern Tech Web Application

A sleek, responsive, and performance-optimized modern technology company web platform built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

![TechFlow Preview](./preview.png)

---

## 🌟 Key Features

- **Dynamic Hero Section**: Parallax floating background orbs that respond smoothly to user scrolling, paired with modern gradient typography.
- **Interactive Solutions Grid**: Showcase of core technology offerings (Web Development, AI Solutions, Cloud Integration, Product Design) featuring glassmorphic hover elevations and glowing gradients.
- **Strategic Company Story**: Clear value proposition, mission statements, and core philosophy checklist.
- **Process Roadmap**: Visual 4-step execution workflow (`01 Discovery` ➔ `02 Strategy` ➔ `03 Development` ➔ `04 Launch`).
- **Social Proof & Testimonials**: Client reviews with 5-star ratings and trust badges.
- **High-Impact CTA & Footer**: Conversion-focused engagement sections and cohesive branding.
- **Fully Responsive & Accessible**: Designed from mobile-first to widescreen desktop displays with seamless viewport adaptation.
- **Ultra-Fast Performance**: Built on Vite with zero runtime overhead and optimized assets.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) / [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajatt738/techflow-webapp.git
   cd techflow-webapp
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` to see the live app.
